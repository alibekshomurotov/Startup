# UstaTop — Mahallada Usta Topish Platformasi

Mahallangizdagi malakali va ishonchli ustalarni (santexnik, elektrik, konditsioner ustasi, mebel ustasi, maishiy texnika ustasi, qurilish ustasi) tez topish, narxlarni solishtirish va buyurtma berish uchun zamonaviy veb-platforma.

## 🚀 Texnologiyalar
- **HTML5** — Semantik va qulay tuzilma
- **CSS3** — Zamonaviy responsiv dizayn (Desktop, Tablet, Mobile), Instagram & YouTube uslubidagi UI, space effektlari, shimmer va mikro-animatsiyalar
- **Vanilla JavaScript** — Sof JavaScript, frameworklarsiz, barcha ma’lumotlar brauzerning `localStorage` xotirasida saqlanadi
- **GitHub Pages** — Server talab qilmaydi, to‘g‘ridan-to‘g‘ri statik tarzda ishlaydi

## 📱 Asosiy imkoniyatlar
1. **O‘zbekiston bo‘yicha hududiy qidiruv:** Barcha viloyatlar va tuman/shaharlar bo‘yicha bog‘langan (cascading) filtrlar.
2. **Kategoriya bo‘yicha tezkor tanlov:** Stories/Reels uslubidagi ommabop xizmatlar karuseli.
3. **6 ta rasmiy tekshirilgan usta:** Azizbek, Jasur, Sardor, Akmal, Bekzod, Diyor profillari, reytinglari va xizmat narxlari.
4. **Buyurtma berish va qoralamalar:** Buyurtma shakli, ma'lumotlarni tahrirlash va tasdiqlash bilan bekor qilish.
5. **AI Texnik Maslahatchi:** Uy ta’mirlash masalalarida aqlli tavsiyalar va yechimlar.
6. **100% Responsiv:** Kompyuter, planshet va mobil telefonlar (pastki navigatsiya paneli bilan) uchun moslangan.

## 🌐 GitHub Pages-da ishga tushirish
1. Ushbu repozitoriyni GitHub-ga yuklang.
2. Repozitoriy sozlamalariga kiring: **Settings** -> **Pages**.
3. **Branch** bo‘limida `main` (yoki `master`) ni tanlang va **Save** tugmasini bosing.
4. Bir necha daqiqada sayt quyidagi manzilda ishga tushadi: `https://<sizning-nikingiz>.github.io/<repo-nomi>/`
